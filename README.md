# Urban Flow

## Sprint actual: Sprint 1

## Objetivo
Aplicar conocimientos de versionado de código, organización, limpieza de datos
y utilización de pandas sobre el dataset histórico de multas por exceso de
velocidad de la localidad de Vaalserberg.

## Introducción y contexto
La localidad de Vaalserberg (Bélgica) cuenta con un sistema de radares urbanos
para la detección de infracciones por exceso de velocidad. Los registros
históricos provienen de sistemas heredados que presentan errores de formato y
datos faltantes. En este sprint depuramos los datos del sistema viejo para
obtener información relevante y permitir su futura incorporación al nuevo
sistema sin inconsistencias.
